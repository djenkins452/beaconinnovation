# AIMS Field — Release Notes

- **Version:** 0.4.0
- **Build:** 11
- **Release Date:** August 4, 2026

## What's New
- Serial Accountability: a dedicated dashboard with a master serial register, status chips, four review tiles, and a searchable drill-down — plus an investigative Serial Detail view with a progress bar and a Recently Verified list.
- Completed BOMs now render directly as an Army Component Listing / Hand Receipt, and the exported binder emits that completed hand receipt with signatures.
- A new app-wide Army-green surface system, with Home as a workflow launcher and the Shortages tab as the Inventory Metrics review center.
- Continuous execution now spans the whole Inventory Event — no premature "Complete" after one of several BOMs.

## Bug Fixes
- Fixed the Inventory Event deletion lifecycle — no orphaned Planner blocks or "Plan Drifted" banner.
- Fixed an exported-BOM regression so the binder reliably emits the completed hand receipt with signatures.

## Known Issues
- None reported.
