# AIMS Field — Release Notes

- **Version:** 0.4.0
- **Build:** 7
- **Release Date:** July 31, 2026

## What's New
- Sub Hand Receipt (SHR) accountability: import an SHR and AIMS silently verifies property against it, then surfaces the result in the Commander's Report with a dedicated SHR Accountability / Property Verification section.
- Executive SHR report: BLUF statement, sensitive-item elevation, and an explicit certification recommendation.
- Inventory Events are now first-class: run and track multiple events, with a multi-event Home.
- Export complete Inventory Events as binder folders — including batch export of several at once — into one destination; the imported SHR and its verification state travel inside the exported record.
- The Planner reads like a real schedule: chronological order with visible times.

## Bug Fixes
- A "Missing End Item" now correctly means the asset itself is absent, not merely a short component.

## Known Issues
- None reported.
