# AIMS Field — Release Notes

- **Version:** 0.3.0
- **Build:** 4
- **Release Date:** July 28, 2026

## What's New
- Import Army inventories directly from BOM PDFs — pick a whole folder or selected files; AIMS reads every BOM, consolidates duplicates, and builds ready-to-count inventories offline.
- One BOM can create any number of inventories at once. Set the quantity, assign TO/FROM (name + title) and SLOC once, and those details flow into the signatures and the exported document — no re-entry.
- Duplicate inventories collapse into one group and run as a continuous "Item N of M" loop that advances automatically.
- Each imported line shows its location and reference image, with a full Item Details view for every Army field.
- Clearer single "next action" inventory status and a smoother End Item workflow; faster exception entry.
- Reopen a completed inventory to make corrections, and review a locked inventory's photos and notes read-only.

## Bug Fixes
- Restored whole-folder selection in Import so PDFs no longer have to be chosen one at a time.
