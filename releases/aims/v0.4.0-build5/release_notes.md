# AIMS Field — Release Notes

- **Version:** 0.4.0
- **Build:** 5
- **Release Date:** July 30, 2026

## What's New
- Inventory Planner: schedule equipment inventories on a calendar of Inventory Events, with the Home screen badging what still needs scheduling.
- Signature Queue: complete your counts first, then certify BOMs together in one deferred, centralized signing step — with Select All / Clear All.
- Continuous Inventory Events: move BOM→BOM with no screen in between; one "Inventory Event Complete" at the end, and group inventories show a clear Group Complete summary.
- Workflow-aware Home dashboard that always points to the next best action, with tiles that light up based on your actual data.
- Built-in documentation: a complete User Guide, an Administrator Guide, per-screen Page Help, and in-app doc search — all offline.
- Signing forms now behave like native iOS forms (smooth focus, no keyboard flicker), and every Issued By / Received By field auto-uppercases like SLOC.
- Shortage reports aggregate by item for a cleaner, command-ready view.

## Bug Fixes
- Editable quantity directly on the Review Imported BOMs screen.
- A deleted plan no longer strands you on a dead-end screen.
- A missing End Item is recorded correctly, with no observed serial.

## Known Issues
- None reported.
